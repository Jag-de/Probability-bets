A few months ago, I heard so many people talking about an app.  
Got curious and downloaded it from the App Store.  
Then suddenly, I started seeing ads telling me to download the same app.

**Isn’t that just a waste of resources?**

There must already be a system to detect this, right? If not, hey developers, I’ve just submitted a user requirement.

## Project Idea

The model predicts whether a user is likely to buy a product based on characteristics such as:

- Age
- Gender
- Income
- ProductCategory

Based on these characteristics, the model helps determine **whether a user should be targeted with an ad**.

## Goal

Make advertising more relevant and avoid wasting resources on users who are unlikely to be interested.
